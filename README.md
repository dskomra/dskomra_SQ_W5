# Side Quest Week 5

## Setup and Interaction Instructions

**Running the Sketch**

Right-click on index.html and open in broswer using Live Server.

**Controls**

Use the W, A, S, and D keys to move.

**Goal of the Game**

Collect all 3 coins and reach the green exit to win!
